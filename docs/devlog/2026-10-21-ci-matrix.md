# 跨平台 CI 构建矩阵与检查拆分

- 日期：2026-10-21；任务 ID：ci-matrix；执行者：基层 Agent。
- 目标与状态：实现中 / 待审查。已完成本地工作流拆分、跨平台构建矩阵定义、Linux 后端特性最小补充、包归档设计及本地静态/语法核验；未提交、未推送，未在云端触发真实流水线。

## 改动与决定

1. **工作流拆分与重命名**：
   - 将 `.github/workflows/windows.yml` 重命名为 `ci.yml`，workflow 名称设为 `CI`。
   - 拆分为两个并行 job：
     - `code-check`：运行于 `windows-2022`，负责代码规范与覆盖检查：`cargo fmt --all -- --check`、`cargo check --locked --all-targets`、`cargo clippy --locked --all-targets -- -D warnings` 与 `cargo test --locked`。
     - `build`：跨平台原生构建矩阵，`fail-fast: false`，仅编译 Debug profile（默认 cargo profile，不加 `--release`，不修改全局 profiles）。
2. **构建矩阵与运行器**：
   - 包含 4 个原生平台与目标：
     - `windows-2022` (`x86_64-pc-windows-msvc`) -> `githux.exe`
     - `ubuntu-24.04` (`x86_64-unknown-linux-gnu`) -> `githux`
     - `macos-15` (`aarch64-apple-darwin`) -> `githux`
     - `macos-15-intel` (`x86_64-apple-darwin`) -> `githux`
3. **依赖与环境准备**：
   - 全平台使用固定 Rust `1.98.1` 工具链（与 `rust-toolchain.toml` 保持一致）并添加对应 target，使用 `--locked` 保证依赖锁一致。
   - Linux 安装基础编译依赖与 GPUI 运行时库：`build-essential`、`pkg-config`、`clang`、`cmake`、`libfontconfig1-dev`、`libfreetype6-dev`、`libxkbcommon-dev`、`libxkbcommon-x11-dev`、`libwayland-dev`、`libx11-xcb-dev`、`libxcb1-dev`、`libssl-dev`。Vulkan 由运行时动态加载。
   - macOS：Ely 默认开启 `runtime_shaders`，经 `gpui_platform` 传递至 `gpui_apple`，构建期生成并嵌入着色器源码，运行时编译；无需在构建期下载独立 Metal 编译器工具链，使用 GitHub runner 默认 Xcode SDK。
4. **Linux 窗口后端特性最小修复**：
   - 经核对，`gpui-pre-platform = 0.3.8` 默认 features 为空，Linux 平台依赖默认未启用窗口后端（`x11`/`wayland`）。为避免 Linux 构建产物成为无头（headless）binary，在 `Cargo.toml` 中针对 `target_os = "linux"` 条件补充 `gpui_platform` 的 `x11` 与 `wayland` 特性。
   - 补充后经 `cargo metadata` 离线更新 `Cargo.lock`，解析精确匹配现有缓存包，未升级任何现有依赖，其他平台依赖树与特性保持不变。
5. **构件打包与上传**：
   - 使用 `actions/upload-artifact@v4` 与 `Swatinem/rust-cache@v2`（各 target 独立缓存 key）。
   - 仅提取目标 binary 与两个内置字体许可证（`OFL-NotoSans.txt`、`OFL-GoogleSansCode.txt`），避免上传庞大的 target 目录。
   - Windows 打包为目录由 artifact 压缩；macOS 与 Linux 打包为 `.tar.gz` 归档以保留可执行文件权限位（GitHub artifact zip 会重置 Unix execute bit）。
   - 设置 `if-no-files-found: error`。
6. **流程优化与文档更新**：
   - 增加 concurrency 策略，分支新 push 自动取消同分支旧运行，`main` 分支不取消。
   - 更新文档与代码规范中对 `windows.yml` 的引用及 CI 状态说明。
