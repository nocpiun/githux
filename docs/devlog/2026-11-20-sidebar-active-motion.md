# 侧栏选中背景移动

基线 `10a663a` 的最小复现是从 Home 点击 Settings。目标行立即获得背景和窄指示条，两个位置都直接跳转。仓库行也采用相同的逐行背景切换，窄指示条随各行在独立列表中裁剪。

本轮在正式 Shell 中把 Home、Settings 和仓库的选中背景交给一块共享绘制层。活跃行和上一个目标的实际布局在 prepaint 采集。快速切换从最后绘制的背景位置和尺寸重启 180ms ease-out。窄指示条、行文字与图标在切换当帧继续由目标行绘制，hover 与焦点留在各自的交互节点。固定导航到仓库的过渡可经过组标题。背景进入仓库视口后受其底边限制，仓库间过渡也受视口顶边裁剪。

PR #99 的侧栏差异已对照其远端 head `e85216c`。它为普通行增加按压填充和真实焦点环，为 sash 增加圆角，并将固定导航的选中底色改为 `colors.active`。这些交互和 sash 继续由各自节点绘制。若 #99 先合入，合并时将其固定导航底色转给共享绘制层，并在新基线复测组合。
