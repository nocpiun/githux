# UI 字体全量改用 Noto Sans SC（Issue 3）开发日志

- 日期：2026-11-10；任务 ID：ui-noto-sc；执行者：基层 Agent。
- 分支：`fix/ui-noto-sc`；基线：`0c619070be103048f9aa033f2f57520372cbebb2`。

## 背景与问题定义

Issue 3：全量 UI 字形（包括英文与中文）统一为 Noto Sans SC。Google Sans Code 保持不变。

在此前实现中，`Githux UI` 是由 Noto Sans（负责 2,965 个 Latin/Greek/Cyrillic 映射）与 Noto Sans SC（负责 Han 及 CJK 标点 30,361 个映射）合并而成的 composite font。负责人要求统一字形风格，全部 UI 字符（拉丁字母、数字、标点及中文字符）均统一来自 Noto Sans SC 官方源，不再混编 Noto Sans Latin。

## 方案与实现

1. **直接从官方 Noto Sans SC 实例化**：
   - 官方源：Noto Sans SC Google Fonts revision `6157dfaa640ca5738b4d1a7070fe389c3036d7fc` (`NotoSansSC[wght].ttf`，SHA-256 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`)。
   - 权重：400 (Regular)、500 (Medium)、600 (SemiBold)、700 (Bold)。
   - 剔除非适用表（`BASE`, `STAT`, `vhea`, `vmtx`），保留完整 GSUB、GPOS、hinting 及水平字形。
   - 保留私有族名 `Githux UI`，以避免与系统 Noto Sans 冲突，并符合 SIL OFL 1.1 许可要求。
   - 移除原先单独混入的 Noto Sans Latin 来源和 `OFL-NotoSans.txt`。

2. **生成脚本与校验**（`scripts/build-ui-fonts.py`）：
   - 重新编写 `scripts/build-ui-fonts.py`，直接从 `NotoSansSC[wght].ttf` 实例化四个字重。
   - 每次生成均自动提取原源字体实例化后的每个 glyph 坐标、端点、flags 及 advance（`signature` 比对），确保逐字形完全忠实于官方 Noto Sans SC。
   - 更新 `sample-glyphs.json` 覆盖中英样本字符的 glyph ID 映射。

3. **文档与许可声明**：
   - 更新 `assets/fonts/README.md`、`THIRD_PARTY_NOTICES.md`、`docs/third-party-assets.md`。
   - 更新 `.github/workflows/ci.yml` 的 artifact 打包步骤（移除已删除的 `OFL-NotoSans.txt`）。
   - 更新 `src/platform/fonts.rs` 与 `examples/fonts.rs` 文档注释。

4. **Google Sans Code**：
   - 完全未改动，保持原有代码字体注册与使用。
