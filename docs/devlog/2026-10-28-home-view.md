## 改动与决定

- 新增 `src/ui/home/**`：`HomeView` 消费现有 `HomeSearchOutcome`/`FeedOutcome`/`HomeError`，不新增网络、凭据、缓存或 domain 类型。
- 用 `RequestBinding` + generation 保护旧响应；`bind` 清空两栏内容、选择与滚动，旧绑定/generation 的成功和错误都被拒绝。该保护不是授权检查，授权核验仍由 host 在服务侧完成。
- 每栏独立持有状态、焦点、选择、`UniformListScrollHandle`、共享 `Bars` 与 `Motion`；一次精确滚轮只消费一次，且不跨栏。
- typed Feed 覆盖 Push/PullRequest/Issues/IssueComment/Watch/Create/Delete/Fork/Release/Public/Member 与 Unknown；缺失字段和未知类型有安全回退，不保留或展示原始 payload。
- Feed 领域模型没有 Issue/PR 全局 id，因此 Feed 激活回调使用稳定事件 id + typed kind，不用仓库内 number 冒充全局 id。
- 刷新由 host 的 `RefreshAvailability` 控制；不可用禁用，refreshing 期间禁止第二次回调。
- 独立预览 `examples/home.rs` 提供 Mixed、Loading/error、Partial、Empty/unavailable、Large 场景；fixtures 和切换器不进入产品路由或运行参数。
- 负责人 2026-10-28 确认的 Home/Feed 默认值记录在 [Home / Feed 页面视图](../home-view.md)，未修改 account-shell 所属的 `product.md`。
- 第一轮 Codex 审查的两条 P2 均已直接修复：Loading 被视为 busy，首次加载或 refreshing 期间拒绝重复刷新；Home/End 显式选择首/末行，不再依赖 delta 符号。新增两项回归测试。
