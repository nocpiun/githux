# Windows 任务工作树与 Rust 编译缓存

2026-11-19 · `worktree-layout` · 协调者

任务工作树现在默认放在 `D:/githux-worktrees`。每棵树保留自己的 `target/`；父目录统一配置 sccache，复用可缓存的编译结果。配置示例和统计方法见[派发说明](../../.agents/skills/githux-agent-dispatch/references/operations.md#本机配置)。主检出与其他项目不继承该配置。

迁移前后对六棵已有工作树核对了分支、HEAD、暂存和未暂存改动及未跟踪源码。正在执行的任务在保存进度后正常退出，在新路径恢复原 Pi 会话。没有清理既有构建产物。

验证：20 项派发脚本测试通过；Cargo 元数据确认六棵迁入的树和本次工作流分支分别使用自己的 `target/`。在两个工作树中分别离线构建同一小型依赖，两个独立输出目录都生成了库，热缓存实测累计 Rust 命中数 0 → 2 → 4。本次未改产品代码，也未用该示例推算整仓构建耗时或磁盘节省量。
