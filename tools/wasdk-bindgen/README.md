# Windows App SDK bindings

Generated by windows-bindgen 0.65.0 from Microsoft.WindowsAppSDK.InteractiveExperiences
1.8.260708001 metadata (10.0.18362.0). Only title-bar, window, dispatcher and input-region
types are selected. Methods referring to unselected types are intentionally omitted;
the generator preserves the ABI slots. Windows system types reuse windows 0.62.2.

From the repository root on Windows:

```powershell
./scripts/prepare-windows-runtime.ps1
cargo run --locked --manifest-path tools/wasdk-bindgen/Cargo.toml --target-dir target/wasdk-bindgen
./scripts/generate-windows-manifest.ps1
cargo fmt --all
```

Commit the generated src/platform/wasdk_bindings.rs with any generator changes.
Normal builds do not download metadata or execute the generator.
